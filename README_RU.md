# SwiftVoice

> Минимальное, быстрое и на 100% локальное приложение для голосовой диктовки на macOS, работающее на базе `whisper.cpp` с ускорением Apple Metal GPU.

🌐 **Language:** [English](README.md) | [Українська](README_UK.md) | [Русский](README_RU.md)

---

```text
Удержание хоткея (напр. Правый ⌥ или ⌘B) → Плавающий HUD-индикатор → Отпускание → whisper.cpp → Ввод текста
```

Аудио и распознавание остаются исключительно на вашем Mac. SwiftVoice не использует сетевые API, не хранит историю диктовок и не слушает микрофон в фоне.

## ✨ Возможности

- **Диктовка Push-to-Talk**: Удерживайте горячую клавишу для записи, отпустите для распознавания и автоматического ввода текста в любое активное текстовое поле.
- **Расшифровка аудиофайлов**: Выберите или перетащите WAV, M4A, MP3 или AAC, локально распознайте запись без личного словаря диктовки, затем отредактируйте, скопируйте или сохраните результат в UTF-8 TXT.
- **Плавающий HUD-индикатор диктовки**: Компактное окно в стиле glassmorphism вверху экрана с живой анимированной звуковой волной во время записи (можно отключить в Настройках).
- **Встроенный загрузчик моделей Whisper**: Выбирайте и скачивайте любую из 6 официальных моделей Whisper (`Tiny`, `Base`, `Small`, `Medium`, `Large v3`, `Large v3 Turbo`) или кастомные бинарники прямо в окне Настроек с отслеживанием прогресса.
- **Автономный движок распознавания**: Зафиксированный `whisper.cpp v1.9.2` и его библиотеки подписаны и встроены в приложение. Установленная версия больше не зависит от каталога с исходниками.
- **Интерактивный рекордер хоткеев**: Назначайте одиночные клавиши (`Правый ⌥`, `Левый ⌃`, `Fn`) или любые комбинации (`⌘B`, `⌥Space`, `⌃Shift+V`) с автоматической проверкой системных конфликтов macOS.
- **Импорт и Экспорт словаря**: Полная поддержка форматирования **JSON** и **CSV/TXT** для резервного копирования, обмена и восстановления терминов и их произношений.
- **Акустическое эхоподавление (AEC)**: Нативная интеграция Apple Voice Processing автоматически отсекает звук фоновой музыки, фильмов или YouTube из динамиков Mac без изменения системной громкости.
- **Бесшовный режим AirPods и гарнитур**: Мгновенный запуск записи без прерываний воспроизведения музыки и полная поддержка работы с закрытой крышкой MacBook (Clamshell mode) с внешним дисплеем.
- **Динамическая адаптация микрофонов**: Автоматическое переподключение звукового канала при подключении или отключении AirPods, внешних гарнитур или USB-микрофонов.
- **Мультиязычный интерфейс**: Полная локализация на английский, русский и украинский языки с мгновенным переключением без перезапуска.
- **Нативная интеграция с macOS**: Написано на Swift 6 & SwiftUI. Поддерживает индикатор в меню-баре, переключение микрофонов, нативный автозапуск (`SMAppService`) и вкладку «О программе».

## 📋 Требования

- macOS 14.0 (Sonoma) или новее на Apple Silicon (M1/M2/M3/M4).
- Xcode Command Line Tools (`xcode-select --install`).
- CMake.
- Git.

## 🚀 Быстрый запуск (Автоматическая установка)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/dgalact/SwiftVoice.git
   cd SwiftVoice
   ```

2. Запустите скрипт установки:
   ```bash
   chmod +x scripts/*.sh
   ./scripts/setup.sh
   ```
   *Скрипт `setup.sh` автоматически соберёт `whisper.cpp` с Metal, соберёт SwiftVoice и установит его в `/Applications/SwiftVoice.app`. Выбрать или скачать нужную модель Whisper вы сможете прямо в Настройках приложения.*

3. Запустите SwiftVoice:
   ```bash
   open "/Applications/SwiftVoice.app"
   ```

4. Предоставьте разрешения macOS при первом запуске:
   - **Микрофон**: Необходим для записи аудио во время диктовки.
   - **Accessibility**: Необходим для автоматического ввода текста в активное окно.

## 🛠️ Скрипты сборки и установки

### Сборка приложения
```bash
./scripts/build-app.sh
open "dist/SwiftVoice.app"
```

### Установка приложения
```bash
./scripts/install-app.sh
open "/Applications/SwiftVoice.app"
```

### Подготовка `whisper.cpp`
```bash
./scripts/bootstrap-whisper.sh
```
*Использует проверенный релиз `whisper.cpp` `v1.9.2` с зафиксированным коммитом, затем очищает `vendor/whisper.cpp/build` перед CMake. Новые версии upstream никогда не загружаются неявно.*

## ⚙️ Настройки

Окно настроек открывается через иконку в меню-баре, `Command+,` или повторным запуском `SwiftVoice.app`.

- **Основные**: Выбор языка интерфейса, интерактивный рекордер Push-to-Talk, тумблер плавающего HUD-индикатора, автозапуск и выбор микрофона.
- **Словарь**: Пользовательская терминология, замена произношений и кнопки **Импорт/Экспорт** (JSON и CSV).
- **Распознавание**: Встроенный движок `whisper.cpp v1.9.2`, загрузчик и селектор моделей, выбор пользовательской модели, автоматическое определение языка и сведения о конфиденциальности.
- **Расшифровка**: Локальная обработка WAV/M4A/MP3/AAC с редактируемым результатом, копированием и сохранением TXT. Личный словарь диктовки намеренно не применяется.
- **О программе**: Сведения о версии (`v1.3.0`), лицензия и ссылки на репозиторий проекта.

Файл словаря хранится по пути:
```text
~/Library/Application Support/SwiftVoice/dictionary.json
```

Загруженные модели хранятся независимо от исходников:
```text
~/Library/Application Support/SwiftVoice/models/
```
