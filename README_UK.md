# SwiftVoice

> Мінімальний, швидкий та на 100% приватний локальний додаток для голосової диктовки на macOS, що працює на базі `whisper.cpp` з прискоренням Apple Metal GPU.

🌐 **Language:** [English](README.md) | [Українська](README_UK.md) | [Русский](README_RU.md)

---

> **Як це працює:** Утримання гарячої клавіші (наприклад, правий ⌥ або ⌘B) → Плаваючий HUD-індикатор → Відпускання → `whisper.cpp` → Введення тексту

Аудіо та розпізнавання залишаються виключно на вашому Mac. SwiftVoice не використовує мережеві API, не зберігає історію диктовок та не слухає мікрофон у фоновому режимі.

## ✨ Можливості

- **Диктовка Push-to-Talk**: Утримуйте гарячу клавішу для запису, відпустіть для розпізнавання та автоматичного введення тексту у будь-яке активне текстове поле.
- **Тривале диктування**: Натисніть окрему настроювану гарячу клавішу для запису без утримання, потім натисніть її знову або Escape для зупинки й розпізнавання.
- **Live Text системного звуку**: Записуйте звук Mac із відео, курсів або інших програм, поки короткі фрагменти з межами за паузами з’являються у плаваючому вікні Live Text. Зупинка гарячою клавішею або Escape автоматично копіює об’єднаний результат.
- **Локальний Live-переклад**: Виберіть будь-яку цільову мову Apple Translation, а початкова мова визначиться автоматично. Накопичений Live Text перекладається знову після появи нового контексту, а після зупинки підсумковий переклад копіюється автоматично.
- **Останній текст**: Останнє успішне диктування поточного сеансу завжди можна скопіювати через меню SwiftVoice.
- **Транскрипція аудіофайлів**: Оберіть або перетягніть WAV, M4A, MP3 чи AAC, локально розпізнайте запис без особистого словника диктування, а потім відредагуйте, скопіюйте або збережіть результат у UTF-8 TXT.
- **Плаваючий HUD-індикатор диктовки**: Компактне вікно у стилі glassmorphic у верхній частині екрана з живою анімованою звуковою хвилею під час запису (можна вимкнути в Налаштуваннях).
- **Вбудований завантажувач моделей Whisper**: Обирайте та завантажуйте будь-яку з 6 офіційних моделей Whisper (`Tiny`, `Base`, `Small`, `Medium`, `Large v3`, `Large v3 Turbo`) або кастомні бінарники прямо у вікні Налаштувань з відстеженням прогресу.
- **Автономний рушій розпізнавання**: Зафіксований `whisper.cpp v1.9.2` та його бібліотеки підписані й вбудовані в додаток. Установлена версія більше не залежить від каталогу з вихідним кодом.
- **Інтерактивний рекордер гарячих клавіш**: Призначайте поодинокі клавіші (`Правий ⌥`, `Лівий ⌃`, `Fn`) або будь-які комбінації (`⌘B`, `⌥Space`, `⌃Shift+V`) з автоматичною перевіркою системних конфліктів macOS.
- **Імпорт та Експорт словника**: Повна підтримка форматів **JSON** та **CSV/TXT** для резервного копіювання, обміну та відновлення термінів і їх вимов.
- **Акустичне ехопоглинання (AEC)**: Нативна інтеграція Apple Voice Processing автоматично відсікає звук фонової музики, фільмів або YouTube з динаміків Mac без зміни системної гучності.
- **Безшовний режим AirPods та гарнітур**: Миттєвий запуск запису без переривань відтворення музики та повна підтримка роботи із закритою кришкою MacBook (Clamshell mode) із зовнішнім монітором.
- **Динамічна адаптація мікрофонів**: Автоматичне перепідключення звукового каналу під час підключення або відключення AirPods, зовнішніх гарнітур чи USB-мікрофонів.
- **Мультиязычний інтерфейс**: Повна локалізація на англійську, українську та російську мови з миттєвим перемиканням без перезапуску.
- **Нативна інтеграція з macOS**: Написано на Swift 6 & SwiftUI. Підтримує індикатор у меню-барі, перемикання мікрофонів, нативний автозапуск (`SMAppService`) та вкладку «Про програму».

## 🚀 Встановлення готового додатка

1. Завантажте останній `SwiftVoice-<version>-macOS-arm64.zip` із [GitHub Releases](https://github.com/dgalact/SwiftVoice/releases/latest).
2. Розпакуйте архів і перемістіть `SwiftVoice.app` до `/Applications`.
3. Під час першого запуску натисніть додаток із Control і виберіть **Відкрити**. Поточний реліз підписано ad-hoc і не нотаризовано сертифікатом Apple Developer ID.
4. Надайте доступ до мікрофона й Accessibility, а потім завантажте модель Whisper у **Налаштування → Розпізнавання**.

Готовий додаток підтримує Mac з Apple Silicon і не потребує Xcode, CMake, Git або вихідного коду.

## 🧑‍💻 Збірка з вихідного коду

Збірка потрібна лише для розробки. Попередньо встановіть Xcode Command Line Tools, CMake та Git.

1. Клонуйте репозиторій:
   ```bash
   git clone --recurse-submodules https://github.com/dgalact/SwiftVoice.git
   cd SwiftVoice
   ```

2. Запустіть скрипт встановлення:
   ```bash
   chmod +x scripts/*.sh
   ./scripts/setup.sh
   ```
   *Скрипт `setup.sh` автоматично збере `whisper.cpp` з Metal, збере SwiftVoice та встановить його в `/Applications/SwiftVoice.app`. Обрати або завантажити потрібну модель Whisper ви зможете прямо в Налаштуваннях додатка.*

3. Запустіть SwiftVoice:
   ```bash
   open "/Applications/SwiftVoice.app"
   ```

4. Надайте дозволи macOS при першому запуску:
   - **Мікрофон**: Необхідний для запису аудіо під час диктовки.
   - **Accessibility**: Необхідний для автоматичного введення тексту в активне вікно.

## 🛠️ Скрипти для розробки

### Збірка додатка
```bash
./scripts/build-app.sh
open "dist/SwiftVoice.app"
```

### Встановлення додатка
```bash
./scripts/install-app.sh
open "/Applications/SwiftVoice.app"
```

### Підготовка релізу
```bash
./scripts/package-release.sh
```
Створює та перевіряє arm64 ZIP і контрольну суму SHA-256 у каталозі `release/`.

Публічні релізи автоматично збираються на Apple Silicon runner із `macos-15`. Змініть `CFBundleShortVersionString` у `Resources/Info.plist`, закомітьте й надішліть зміну, а потім надішліть відповідний тег, наприклад `v1.4.0`. GitHub перевірить відповідність версії тегу, створить ZIP і контрольну суму та опублікує GitHub Release. Звичайні коміти реліз не публікують.

### Підготовка `whisper.cpp`
```bash
./scripts/bootstrap-whisper.sh
```
*Використовує перевірений реліз `whisper.cpp` `v1.9.2` із зафіксованим комітом, а потім очищає `vendor/whisper.cpp/build` перед CMake. Нові версії upstream ніколи не завантажуються неявно.*

## ⚙️ Налаштування

Вікно налаштувань відкривається через іконку в меню-барі, `Command+,` або повторним запуском `SwiftVoice.app`.

- **Основні**: Вибір мови інтерфейсу, окремі гарячі клавіші Push-to-Talk і тривалого запису, тумблер плаваючого HUD-індикатора, автозапуск та вибір мікрофона.
- **Гаряча клавіша системного звуку**: Третя комбінація запускає й зупиняє запис лише системного звуку. Під час першого використання macOS запросить дозвіл на запис екрана й системного аудіо.
- **Словник**: Користувацька термінологія, заміна вимов та кнопки **Імпорт/Експорт** (JSON та CSV).
- **Розпізнавання**: Вбудований рушій `whisper.cpp v1.9.2`, завантажувач і селектор моделей, вибір користувацької моделі, автоматичне визначення мови та відомості про конфіденційність.
- **Транскрипція**: Локальна обробка WAV/M4A/MP3/AAC з редагованим результатом, копіюванням і збереженням TXT. Особистий словник диктування навмисно не застосовується.
- **Про програму**: Відомості про версію, ліцензія та посилання на репозиторій проєкту.

Файл словника зберігається за шляхом:
```text
~/Library/Application Support/SwiftVoice/dictionary.json
```

Завантажені моделі зберігаються незалежно від вихідного коду:
```text
~/Library/Application Support/SwiftVoice/models/
```
