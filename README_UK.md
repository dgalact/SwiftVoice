# SwiftVoice

> Мінімальний, швидкий та на 100% приватний локальний додаток для голосової диктовки на macOS, що працює на базі `whisper.cpp` з прискоренням Apple Metal GPU.

🌐 **Language:** [English](README.md) | [Українська](README_UK.md) | [Русский](README_RU.md)

---

```text
Утримання гарячої клавіші (напр. Правий ⌥ або ⌘B) → Плаваючий HUD-індикатор → Відпускання → whisper.cpp → Введення тексту
```

Аудіо та розпізнавання залишаються виключно на вашому Mac. SwiftVoice не використовує мережеві API, не зберігає історію диктовок та не слухає мікрофон у фоновому режимі.

## ✨ Можливості

- **Диктовка Push-to-Talk**: Утримуйте гарячу клавішу для запису, відпустіть для розпізнавання та автоматичного введення тексту у будь-яке активне текстове поле.
- **Плаваючий HUD-індикатор диктовки**: Компактне вікно у стилі glassmorphic у верхній частині екрана з живою анімованою звуковою хвилею під час запису (можна вимкнути в Налаштуваннях).
- **Вбудований завантажувач моделей Whisper**: Обирайте та завантажуйте будь-яку з 6 офіційних моделей Whisper (`Tiny`, `Base`, `Small`, `Medium`, `Large v3`, `Large v3 Turbo`) або кастомні бінарники прямо у вікні Налаштувань з відстеженням прогресу.
- **Інтерактивний рекордер гарячих клавіш**: Призначайте поодинокі клавіші (`Правий ⌥`, `Лівий ⌃`, `Fn`) або будь-які комбінації (`⌘B`, `⌥Space`, `⌃Shift+V`) з автоматичною перевіркою системних конфліктів macOS.
- **Імпорт та Експорт словника**: Повна підтримка форматів **JSON** та **CSV/TXT** для резервного копіювання, обміну та відновлення термінів і їх вимов.
- **Акустичне ехопоглинання (AEC)**: Нативна інтеграція Apple Voice Processing автоматично відсікає звук фонової музики, фільмів або YouTube з динаміків Mac без зміни системної гучності.
- **Безшовний режим AirPods та гарнітур**: Миттєвий запуск запису без переривань відтворення музики та повна підтримка роботи із закритою кришкою MacBook (Clamshell mode) із зовнішнім монітором.
- **Динамічна адаптація мікрофонів**: Автоматичне перепідключення звукового каналу під час підключення або відключення AirPods, зовнішніх гарнітур чи USB-мікрофонів.
- **Мультиязычний інтерфейс**: Повна локалізація на англійську, українську та російську мови з миттєвим перемиканням без перезапуску.
- **Нативна інтеграція з macOS**: Написано на Swift 6 & SwiftUI. Підтримує індикатор у меню-барі, перемикання мікрофонів, нативний автозапуск (`SMAppService`) та вкладку «Про програму».

## 🚀 Швидкий запуск (Автоматичне встановлення)

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/dgalact/SwiftVoice.git
   cd SwiftVoice
   ```

2. Запустіть скрипт встановлення:
   ```bash
   chmod +x scripts/*.sh
   ./scripts/setup.sh
   ```
   *Скрипт `setup.sh` автоматично збере `whisper.cpp` з Metal, збере SwiftVoice та встановить його в `/Applications/SwiftVoice.app`. Обрати або завантажити потрібну модель Whisper ви зможете прямо в Налаштуваннях додатка.*

3. Запустіть SwiftVoice:
   ```bash
   open "/Applications/SwiftVoice.app"
   ```

4. Надайте дозволи macOS при першому запуску:
   - **Мікрофон**: Необхідний для запису аудіо під час диктовки.
   - **Accessibility**: Необхідний для автоматичного введення тексту в активне вікно.

## 🛠️ Скрипти збірки та встановлення

### Збірка додатка
```bash
./scripts/build-app.sh
open "dist/SwiftVoice.app"
```

### Встановлення додатка
```bash
./scripts/install-app.sh
open "/Applications/SwiftVoice.app"
```

### Підготовка `whisper.cpp`
```bash
./scripts/bootstrap-whisper.sh
```
*Автоматично очищає `vendor/whisper.cpp/build` перед CMake для запобігання конфліктам.*

## ⚙️ Налаштування

Вікно налаштувань відкривається через іконку в меню-барі, `Command+,` або повторним запуском `SwiftVoice.app`.

- **Основні**: Вибір мови інтерфейсу, інтерактивний рекордер Push-to-Talk, тумблер плаваючого HUD-індикатора, автозапуск та вибір мікрофона.
- **Словник**: Користувацька термінологія, заміна вимов та кнопки **Імпорт/Експорт** (JSON та CSV).
- **Розпізнавання**: Вбудований завантажувач та селектор моделей Whisper, шляхи до бінарника `whisper-cli` та файла моделі, вибір мови та відомості про конфіденційність.
- **Про програму**: Відомості про версію (`v1.0.0`), ліцензія та посилання на репозиторій проєкту.

Файл словника зберігається за шляхом:
```text
~/Library/Application Support/SwiftVoice/dictionary.json
```
